# 한양대 풋살동아리 앱 설치·운영 안내

멤버가 이메일·비밀번호로 회원가입하고, 동아리장이 승인하면 평점·등급, 라인업, 활동 투표, 일정을 쓰는 웹앱입니다. 아이폰·삼성폰 모두 홈 화면에 앱처럼 설치할 수 있습니다.

## 1. Firebase 준비 (동아리장 1회)
1. console.firebase.google.com → **프로젝트 만들기**
2. **빌드 → Authentication → 시작하기 → 이메일/비밀번호** 사용 설정
3. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → 프로덕션 모드
4. **Firestore Database → 규칙** 탭에 `firestore.rules` 파일 내용을 전부 붙여 넣고 **게시**
5. **프로젝트 설정 → 내 앱 → 웹(</>)** 으로 앱 등록 → 나온 `firebaseConfig` 값을 `config.js`에 넣기

## 2. 인터넷 주소 만들기 (둘 중 하나)
- **Netlify Drop**: PC에서 app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓기 → 주소 생성
- **GitHub Pages**: 저장소에 파일을 올리고 Settings → Pages 에서 배포

주소가 생기면 Firebase **Authentication → 설정 → 승인된 도메인**에 그 주소(예: `xxx.netlify.app`)를 추가하세요. 추가하지 않으면 비밀번호 재설정 메일 링크 등이 막힐 수 있어요.

## 3. 처음 시작
1. 동아리장이 **가장 먼저** 회원가입 → 로그인 후 **내가 동아리장이에요** 버튼을 누르기 (가장 먼저 누른 1명만 동아리장이 됩니다)
2. 동아리원에게 주소 공유 → 각자 회원가입 → 동아리장이 홈의 **가입 신청**에서 승인
3. 동아리장은 멤버 이름을 눌러 **운영진으로 지정**할 수 있어요. 운영진도 가입 승인과 계정 없는 멤버 추가가 가능해요.

## 홈 화면에 설치
- **아이폰**: Safari로 주소 열기 → 공유 버튼 → **홈 화면에 추가**
- **삼성폰**: Chrome/삼성 인터넷으로 주소 열기 → 메뉴 → **홈 화면에 추가** 또는 **앱 설치**

## 파일
| 파일 | 내용 |
|---|---|
| index.html | 앱 본체 |
| config.js | Firebase 설정값, 동아리 이름 |
| firestore.rules | 데이터 보안 규칙 (Firebase 콘솔에 붙여 넣기) |
| manifest.webmanifest, sw.js, icons/ | 홈 화면 설치용 |

## 보안 규칙 요약
- 승인 전에는 자기 가입 정보만 볼 수 있어요.
- 승인된 멤버와 운영진만 동아리 데이터를 보고 쓸 수 있어요.
- 평가·투표는 각자 자기 것만 고칠 수 있어요. 앱에는 평균 점수만 표시돼요.
- 무료 요금제(Spark)로 동아리 규모에서는 비용이 들지 않아요.
